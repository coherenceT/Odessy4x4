## How It Works:

When a user clicks "VIEW DETAILS" on any product:
1. Opens `product-{id}.html` (e.g., `product-24.html`)
2. Automatically redirects to `product-detail.html?id=24`
3. JavaScript loads the product data from the products array
4. Displays:
   - Product image
   - Name, price, stock status
   - Part number
   - Full description
   - Key features list
   - Technical specifications
   - Add to Cart & Enquire buttons
